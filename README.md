# Personal Portfolio Website — Phạm Thị Nhung

> Website Portfolio cá nhân đa trang được xây dựng bằng **HTML5 Semantic**, **CSS3 hiện đại (Mobile-First, Flexbox, CSS Grid)** và **JavaScript thuần**.

Dự án được xây dựng với mục tiêu thể hiện kỹ năng lập trình web frontend nền tảng, tư duy thiết kế giao diện responsive hoàn chỉnh, chuẩn ngữ nghĩa (Semantic) và tính tiếp cận (Accessibility).

---

## 🚀 Công Nghệ Sử Dụng
- **HTML5:** Cấu trúc ngữ nghĩa (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:**
  - Triết lý thiết kế **Mobile-First**.
  - Bố cục **CSS Grid** & **Flexbox**.
  - Media Queries tương thích: `375px`, `480px`, `768px`, `1024px`, `1440px`.
  - CSS Custom Properties (Variables) & CSS Reset.
  - Zero Horizontal Overflow.
- **JavaScript thuần:** Xử lý tương tác Hamburger Menu & phản hồi gửi biểu mẫu liên hệ.

## 💻 Hướng Dẫn Chạy Cục Bộ
1. Clone hoặc tải mã nguồn về máy:
   ```bash
   git clone https://github.com/nhungphamco/<repo-name>.git
   ```
2. Mở thư mục dự án bằng Visual Studio Code.
3. Mở file `index.html` bằng tiện ích mở rộng **Live Server** (hoặc nhấp đúp để mở trực tiếp trong trình duyệt web).

---

## 🌐 Xuất Bản Lên GitHub Pages (Tùy Chọn)
1. Vào repository trên GitHub, chọn **Settings** > **Pages**.
2. Tại mục **Build and deployment** > **Source**, chọn nhánh `main` và thư mục `/ (root)`.
3. Nhấn **Save** để nhận link website online miễn phí!
